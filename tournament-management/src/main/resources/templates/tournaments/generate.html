Générer le calendrier

Tournoi · Type · 0

Tous les matchs sont créés en une seule opération : en cas d'erreur (équipe déjà occupée au même horaire, par exemple), rien n'est enregistré. Un calendrier ne peut être généré qu'une seule fois ; tant que le tournoi n'a pas démarré, il peut être supprimé puis régénéré. Si le nombre d'équipes n'est pas une puissance de deux (élimination directe), les premières équipes inscrites sont exemptées du premier tour.
